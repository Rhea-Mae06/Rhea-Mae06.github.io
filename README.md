# Rhea Mae Bustamante Portfolio

React portfolio powered by Vite. The former standalone HTML, CSS, and JavaScript implementation has been replaced with a component-based React app.

## Setup

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Create a similar project

```bash
npm create vite@latest
```

Choose **React** and **JavaScript** when prompted.
